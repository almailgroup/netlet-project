# The sign-in page's picture

`welcome.webp` here is the picture across the top of the navy panel beside the
sign-in and create-account forms: NetLet's own street — four stores and the van
being loaded, the towers behind. Replace it by dropping in another file named
`welcome.webp` (or `welcome.png` / `welcome.jpg`); remove it and the panel shows
its words alone.

Landscape 4:3, about 1120 × 840 and under 100 KB, with edges in the brand navy
`#0a285a` so it runs edge to edge in the panel without a visible frame. It is
drawn cropped to 16:10 (a little sky and road go), so keep what matters in the
middle. Decorative — the panel's own words say what the account does — so it
carries no alt text.
